# Überwachen eines Ereignisknotens

Verwenden Sie den Knoten [!UICONTROL Auf ein Ereignis &#x200B;]), [!DNL Adobe Journey Optimizer B2B Edition] beim Eintreten eines Ereignisses einen Journey-Vorgang auszuführen. Konto- und Personenereignisse vergleichen, übereinstimmende Kriterien definieren und Zeitüberschreitungswerte konfigurieren, um zu steuern, wie lange die Journey wartet.

>[!VIDEO](https://video.tv.adobe.com/v/3443243/?captions=ger&quality=12&learn=on)

## Überwachen von Node Essentials

Das Video behandelt die folgenden Themen:

* Der Unterschied zwischen Konto- und Personenereignissen.
* Übereinstimmende Kriterien für Ereignis-Trigger.
* Zeitüberschreitungseinstellungen für Ereignisse, die nicht innerhalb der angegebenen Zeit auftreten.

## Verwandte Dokumentation

Informationen zu unterstützten Ereignissen, Konfigurationsschritten und Optionen für die maximale Wartezeit finden Sie [Lauschen auf ein Ereignis im Benutzerhandbuch](https://experienceleague.adobe.com/de/docs/journey-optimizer-b2b/user/journeys/journey-nodes/listen-for-event-nodes){target="_blank"}.
