# Rollen-Vorlagen für Käufergruppen

Erfahren Sie, wie Sie in [!DNL Adobe Journey Optimizer B2B Edition] Rollenvorlagen erstellen. Diese Vorlagen definieren, wer an einer Kaufentscheidung beteiligt ist, wie Personen Rollen zugewiesen werden und was eine Einkaufsgruppe vollständig macht. In diesem Video wird die Erstellung von Vorlagen, die Rollenkonfiguration und die Veröffentlichung behandelt.

Dieses Tutorial richtet sich an Marketing-Fachleute und Administratoren, die [!DNL Journey Optimizer B2B Edition] für Account-basiertes Marketing verwenden und die richtigen Stakeholder für jedes Account ansprechen möchten.

>[!VIDEO](https://video.tv.adobe.com/v/3433079/?learn=on)

Sie lernen Folgendes:

* Öffnen Sie das Inventar der Rollenvorlagen unter Einkaufsgruppen und unterscheiden Sie zwischen Entwurfsvorlagen und Live-Vorlagen.
* Erstellen Sie eine neue Rollenvorlage mit einem eindeutigen Namen und einer eindeutigen Beschreibung.
* Konfigurieren Sie eine Rolle, einschließlich Gewichtung, automatischer Zuweisung und Vollständigkeitsanforderung.
* Zuweisungsbedingungen für jede Rolle definieren, z. B. Übereinstimmung bei der Stellenbezeichnung.
* Um alle Teilnehmer einzubeziehen, fügen Sie weitere Rollen hinzu, z. B. Entscheidungsträger, Fachkraft und Influencer.
* Legen Sie die Rollenpriorität fest, damit Personen der ersten Rolle zugewiesen werden, deren Bedingungen sie erfüllen.
* Legen Sie mithilfe der Einstellungen für die Vollständigkeitsbewertung die Anzahl der für jede Rolle erforderlichen Mitglieder fest.
* Veröffentlichen Sie eine Vorlage, sodass sich ihr Status in Live ändert und sie für Lösungsinteressen verfügbar ist.

Weitere Informationen finden Sie unter [Kaufen von Gruppenrollenvorlagen](https://experienceleague.adobe.com/en/docs/journey-optimizer-b2b/user/accounts/buying-groups/buying-groups-role-templates) im Benutzerhandbuch.
